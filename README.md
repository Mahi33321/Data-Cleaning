# Data Cleaning – Student Performance Dataset

## Overview
This repository contains the raw and cleaned datasets along with project documentation for a **Student Performance Data Cleaning** project. The objective of this project is to preprocess raw student records by handling missing values, removing inconsistencies, and formatting the data for accurate analysis.

## Repository Contents
* **`student_performance.csv`** – The original raw dataset containing student performance records before preprocessing.
* **`cleaned_student_database (3).csv`** – The final cleaned and structured dataset ready for analysis.
* **`srs 01.pdf`** – Software Requirements Specification (SRS) document outlining the project scope, requirements, and objectives.
* **`Student Performance.pdf`** – Project report detailing the data cleaning steps, observations, and outcomes.

## Key Data Cleaning Steps Performed
* Inspected raw records for missing, null, or duplicate entries.
* Standardized column names and data formats across the dataset.
* Resolved data inconsistencies to produce a reliable, analysis-ready CSV file.
